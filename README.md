# Keuangan Ascendens

Website pencatatan keuangan angkatan Ascendens.

## Deployment
Website menggunakan GitHub Pages melalui GitHub Actions. Setelah workflow berhasil, alamat situs:
https://nabilahzulfa14-oss.github.io/KEUANGAN-ASCENDENS/

## Catatan penting
Versi awal ini adalah prototipe front-end. Data transaksi tersimpan di browser/perangkat yang digunakan (localStorage), belum tersinkron antaranggota dan belum memiliki autentikasi Admin/Member yang aman. Untuk penggunaan bendahara dan anggota secara bersama dengan login serta database terpusat, perlu menghubungkan backend seperti Supabase sebelum memasukkan data keuangan riil.

Saldo awal sengaja diset Rp0 karena nominal saldo awal belum diberikan.
